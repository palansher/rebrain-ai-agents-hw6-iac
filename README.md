# iac-lab — вариант A задания «AI-агенты в DevOps» (Safe IaC packet)

Сервис Launch Control нужно выкатить в прод. Инфраструктурная часть досталась от команды, которая её больше
не поддерживает: Helm-чарт не проходит lint и не рендерится, Kustomize-оверлей не собирается, а в Terraform-плане
лежат изменения, не все из которых безобидны.

Задача — через coding-агента починить чарт и оверлей, написать validation script и минимум три собственных
policy-правила, отревьюить `terraform/plan.json` и довести табло `scripts/score.sh` до **8/8**.
Списка дефектов нет — ищите их валидаторами. `policy/` пустой: правила пишете вы.

```bash
./scripts/tools.sh
./scripts/score.sh --save baseline   # на старте 0/8, логи слоёв - в baseline/
```

Чинить придётся каскадом снизу вверх: пока `helm template` падает, схемная валидация не запускается.
